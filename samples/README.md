# samples

**Not measurements.** These files are hand-made by
[`tools/make_samples.py`](../tools/make_samples.py) so the results page and the
schema tests have data before real submissions exist. Every number in them is
invented. They are marked `"provenance": "sample"`, the device manufacturer
is `SAMPLE`, and the results page shows them only behind a "Show sample data"
toggle, labelled as samples.
